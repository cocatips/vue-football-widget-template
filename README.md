# ⚡ Vue 3 Football Livescore Widget

A minimalist, customizable Vue 3 component for displaying live football match scores. Built with Composition API and `<script setup>`. Fully compatible with Nuxt 3.

## 🛠️ Usage
Simply drop the `MatchWidget.vue` file into your components folder and pass the props.
